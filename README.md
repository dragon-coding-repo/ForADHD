# ADHD家庭支持资源包 · 总览

为 ADHD 患儿家庭制作的一整套支持资源:一份循证手册、一套可打印工具、一个手机网页应用、一组儿童专注力练习,以及微信小程序版。内容依据国内外主流临床指南(AAP / NICE / 中国ADHD防治指南)与公开循证研究整理,**是健康教育与家庭管理工具,不能替代执业医师的诊疗意见**。

> 最快上手:部署后将首页网址发给家人(部署方式见下文"自托管部署");或电脑直接双击 `ADHD家庭助手/index.html` 离线使用。

## 二、三条使用路径

1. **线上网页版(推荐)**:部署到任意静态服务器后,把首页网址发给家人。手机打开后 iPhone「分享→添加到主屏幕」/ Android「菜单→添加到主屏幕」,即得带图标的 App;HTTPS 下会自动缓存,断网也能用。
2. **微信小程序**:用微信开发者工具导入 `微信小程序/` 文件夹(已配测试号AppID,可直接编译预览),注册发布后家人即用即走。类目建议"教育-家庭教育",避开需版号的"游戏"类目——工程内已统一把"游戏"表述为"专注力练习"。
3. **纸质/离线**:打印 Word 手册与 Excel 工具包张贴使用;或电脑直接双击两个 `index.html` 离线运行(注意:本地 file:// 下练习领星与家庭助手不同源互通,部署在同一域名下才互通)。

## 三、内容主线与激励闭环

整个包围绕一条主线组织:**理解孩子 → 找对治疗 → 搭好日常 → 正向激励 → 守护全家心理**。

```
认识ADHD(手册1章/课堂) → 就医诊断(手册2章) → 循证治疗(手册3章: <6岁行为治疗首选, 6-12岁药物+行为+学校)
        ↓
家庭日常(手册4章 → 工具包表格 → 助手App数字化)
        ↓
正向激励闭环:目标打卡⭐ + 专注力练习⭐(家长长按确认) → 积分钱包 → 兑换奖励菜单
        ↓
家校合作(手册5章) + 全家心理支持(手册6章, 热线12356)
```

三个专注力练习对应 ADHD 三项核心执行功能(证据边界见 App 内「家长园地」的诚实版说明,练习不是治疗):

## 四、自托管部署(可选,服务器信息不在本仓库)

本仓库不含任何部署地址、服务器IP与运维配置。想自建线上版,任选一种静态托管:

1. **GitHub Pages(零成本)**:仓库 Settings → Pages 启用,即可获得 `https://<用户名>.github.io/<仓库名>/` 网址;建议目录结构:仓库根放本 README 与三份文档,`app/`(助手)、`game/`(练习)、`files/`(三份下载文档)。练习领星与助手积分互通要求两者**同源**,同仓库 Pages 天然满足;
2. **自己的服务器**:nginx/caddy 指向静态目录即可,无需后端——所有用户数据存在访问者手机本地,服务端无状态;
3. **局域网**:在项目目录运行 `python3 -m http.server 8080`,同网设备访问 `http://<内网IP>:8080`。

注意事项:
- 练习领星写入助手积分,依赖**同源**(同一协议+域名+端口),本地 `file://` 双开不互通;
- PWA"添加到主屏幕+离线缓存"需要 HTTPS(GitHub Pages 自带);
- 请勿把你的真实部署网址、服务器IP、隧道地址提交到公开仓库。
