# ADHD家庭助手 · 微信小程序版

网页版《ADHD家庭助手》+《专注力小游戏》的整体移植:无需下载安装,微信里搜一搜/扫码即用。全部内容同源——星星打卡、快速记录、随身手册、三个专注力练习、呼吸收工、家长长按领星。

## 如何运行(需要你来做的一步)

本项目无法在这台服务器上真机运行——微信小程序必须在**微信开发者工具**中编译预览:

1. 下载安装「微信开发者工具」(官方稳定版,支持 Windows/macOS);
2. 打开工具 → 导入项目 → 选择本文件夹(`微信小程序/`)→ AppID 保持 `touristappid`(测试号)即可先编译体验;
3. 工具内点「预览」生成二维码,自己手机微信扫码即可真机试用;
4. 正式给家人使用:在 [mp.weixin.qq.com](https://mp.weixin.qq.com) 注册小程序(个人主体免费)→ 拿到 AppID 填入 `project.config.json` → 上传代码 → 提交审核 → 发布;审核前可先发「体验版」给家人。

## 合规提示(重要)

- **类目建议**:注册时选择「教育-家庭教育」或「工具-效率」类目。**不要选"游戏"类目**——游戏类小程序需要版号,个人主体无法提供。本项目内部已把"游戏"表述统一为"专注力练习",与教育/工具定位一致。
- 名称建议:「ADHD家庭助手」或「专注力家庭练习」。

## 与网页版的差异

- 网页版是两个网址(助手+游戏),小程序版**合并为一个**,练习赢的星星经家长长按确认直接进积分钱包(同一存储,无需跨域桥接);
- 提示音改为打包内置的4个合成wav(小程序无法合成音频);震动用 wx.vibrate;
- 手册表格在手机上渲染为双栏卡片;热线 12356 点击直接拨打;
- 数据存在各手机微信本地,与网页版互不相通。

## 已知问题修复记录

- **tabBar第5项"练习"未显示(真机导入发现)**:纯文字 tabBar 在部分机型模拟器上渲染异常。已为 5 个 tab 生成标准 81×81 图标(assets/tab/,灰/青两态)并写入 app.json,同时校验器新增图标存在性检查。
- **控制台 "appLaunch with non-empty page stack" 路由错误**:经排查代码中不存在启动即导航(所有跳转都在用户点击处理器里),为开发者工具在多次修复重编译后恢复旧页面栈的噪音。处理:工具栏「工具 → 清除缓存 → 清除全部缓存」后重新「编译」即消失。

- **WXSS编译错误(第一轮)**:WXSS 不支持 `:active` 等伪类(仅支持 ::after/::before),另 `inset` 简写、`aspect-ratio`、`display: grid` 也在部分 wcsc 版本会报错。已全部替换:`:active` → 原生 `hover-class` 按压反馈;`inset` → 四方向展开;`aspect-ratio`/`grid` → 固定尺寸+flex。
- **WXSS编译错误(第二轮,真凶)**:`game.wxss` 中残留了一个**空的 `@keyframes breathbig { }`**(移植时的编辑残渣),wcsc 对空 keyframes 抛 `unexpected token }` 导致整个文件编译失败。已删除(呼吸动画由 class 切换+transition 实现,无需该keyframes),并把"空keyframes块/花括号不平衡"加入静态校验;同时清理了 `calc(... + env(...))` 与 `font-variant-numeric` 两处隐患,并将 `:active`/`inset`/`aspect-ratio`/`grid`/`env`/`calc`/空块 全部列入 `tools/check_mp.js` 黑名单。
