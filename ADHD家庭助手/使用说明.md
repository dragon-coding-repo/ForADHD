# ADHD家庭助手 · 使用说明

> 配套的儿童游戏见同目录 `../专注力小游戏/`,或线上首页的"打开专注力小游戏"。三个小游戏(红绿灯/星星复现/大小擂台)分别练"停下来、记得住、变通快",每次限时收工,赢的星星经家长长按确认存入本App积分钱包。

把《家庭实用工具包》里的纸质表格,变成一部手机就能天天用的应用:

| 模块 | 对应原来的 | 在App里 |
|------|-----------|---------|
| ⭐ 星星打卡 | 代币打卡表+奖励菜单 | 点一下亮星自动计分,攒星兑换奖励,余额自动算 |
| 📝 快速记录 | 行为观察记录/用药记录 | 标签点选,10秒记一笔;好行为也记 |

| 📘 手册 | 家庭指导手册 | 全文随身带,字号可调 |
| 更多 | 家长课堂+求助资源 | 18页课堂要点、心理援助热线12356、数据备份 |

## 怎么打开

**线上访问:** 线上网址由部署者提供(出于隐私考虑,部署地址、服务器IP不入库,见仓库根 README 的"自托管部署")。拿到网址后:打开即是资源首页,点"打开ADHD家庭助手App"进入;iPhone:分享 → 添加到主屏幕,Android:菜单 → 添加到主屏幕。

**自托管(任选其一,详见仓库根 README):**
- GitHub Pages:把 `app/`、`game/`、`files/` 按仓库建议结构放置,启用 Pages 即得 HTTPS 网址,自动支持离线缓存;
- 自己的服务器:nginx/caddy 指向静态目录,无需后端;
- 局域网临时用:在本目录运行 `python3 -m http.server 8080`,同网设备访问 `http://<内网IP>:8080`。

**电脑上(离线):** 直接双击本文件夹的 `index.html` 也能用,数据与线上互不相通。

**部署者备忘(不涉及具体地址):** 领星与助手积分互通要求助手与练习**同源**(同协议+域名+端口);HTTPS 才有 PWA 离线缓存;请勿把真实部署网址提交到公开仓库。

## 数据与隐私

- 所有数据只保存在**这台设备的浏览器本地**(localStorage),不联网、不上传。
- 换手机/清浏览器缓存前,先在"更多 → 导出备份"保存 JSON 文件,新设备上"导入备份"恢复。
- 想清空重来:更多 → 清空全部数据(有两次确认)。

## 与纸质三件套的关系

Word 手册(深度阅读)、Excel 工具包(打印张贴)、PPT 课堂(家长培训)仍然可用;App 是它们的"日常随身版"。内容完全同源。
